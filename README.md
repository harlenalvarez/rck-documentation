# React Canvas Kit documentation — retired

The current RCK website, documentation, playground and benchmarks are maintained in Quicksketch at [reactcanvaskit.com](https://reactcanvaskit.com).

The frozen RCK v1 documentation remains available at [reactcanvaskit.com/v1](https://reactcanvaskit.com/v1). Published v1 documentation links redirect to their archived pages there. The archive documents `@practicaljs/react-canvas-kit`; the current v2 API is documented separately.

This repository was retired on November 5, 2026. It is archived and no longer deploys. Its Azure workflow remains disabled so only Quicksketch deploys to the shared production resource. The original v1 Markdown remains in this repository's history.
